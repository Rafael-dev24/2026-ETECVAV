## 📖 Sobre

Este repositório foi criado para armazenar atividades, exercícios e projetos desenvolvidos na disciplina de **Programação em C++**.

O objetivo é praticar conceitos fundamentais da programação, lógica computacional e desenvolvimento de algoritmos utilizando a linguagem C++.

---

## 🎯 Conteúdos Estudados

- ✅ Lógica de Programação
- ✅ Variáveis e Tipos de Dados
- ✅ Operadores Aritméticos
- ✅ Estruturas Condicionais (`if`, `else`, `switch`)
- ✅ Estruturas de Repetição (`for`, `while`, `do while`)
- ✅ Vetores e Matrizes
- ✅ Funções
- ✅ Ponteiros
- ✅ Arquivos
- ✅ Programação Orientada a Objetos

## ⚙️ Como Executar

### Compilar

```bash
g++ arquivo.cpp -o programa
```

### Executar

```bash
./programa
```

No Windows:

```bash
programa.exe
```
